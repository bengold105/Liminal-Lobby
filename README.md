# Liminal Lobby
A VR Puzzle game where the player enters a hotel lobby and has to memorize the objects within it.

<p align="center">
  <img src="https://github.com/bengold105/Liminal-Lobby/blob/main/gifs/lobby1.gif" alt="gif1" />
</p>

During the game, the player will be put into the same room and have to identify the objects that changed and has to return them to their original state/positions to complete the level.
